Border Beats – Privacy Policy

Last updated: 7 October 2026

Summary

Border Beats runs entirely on the user's own computer. It has no servers of its own and does not collect, sell or share personal data.

TikTok data

  • When the user logs in with TikTok, Border Beats receives an access token and the user's basic profile (display name, profile picture, an account ID). These are stored only in a file on the user's own computer and are used only to show which account is logged in and to post the user's videos.
  • Videos and captions are sent only to TikTok, only after the user confirms each post.
  • The user can log out at any time; this deletes the stored login and asks TikTok to revoke the access.

Other data

Songs, videos and settings the user loads stay in the user's browser and computer. Nothing is sent anywhere else.
