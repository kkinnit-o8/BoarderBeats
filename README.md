# Border Beats

A physics + music simulation for TikTok videos and TikTok LIVE: balls bounce inside a glowing circle, and the song only plays when they collide.

- `index.html` – the whole app. Open it in Brave or Chrome (no install needed).
- `Start Border Beats.bat` + `tiktok-helper.js` – start the app with the TikTok helper, to log in with TikTok and post rendered videos (needs Node.js).
- `TIKTOK-SETUP.txt` – one-time setup for posting to TikTok.
- `docs/` – the public website (home page, Terms of Service, Privacy Policy) served by GitHub Pages.

`tiktok-keys.json` (your TikTok app keys) is private and is not in this repository. On a new computer, start the helper once and paste your keys into the file it creates.
